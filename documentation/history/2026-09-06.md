modal's title too. Two different outcomes from the same requested phrase, both correct:

- The context-menu item is a plain string-literal `.setTitle('Set Auto-Tag')` on a `MenuItem` —

  capitalized). Used **"Set auto-tag"** there instead, flagged to the user why, rather than silently
  picking a different phrase or reaching for a disallowed `eslint-disable`.

  rule doesn't analyze template literals, so it passed as asked, with the exact "Set Auto-Tag"
  capitalization kept. Confirmed by actually running lint against both before deciding, not by
  assuming the rule's reach.
